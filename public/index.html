SSF Merge

Mail merge for PowerPoint. One template block of slides, one set of slides per row of your data, and formatting that survives because nothing re-authors it.

Get the add-in

Download manifest-prod.xml from the latest release and sideload it in PowerPoint. It is early, and it is installable.

Source and progress: github.com/dannbleeker/SSF-Merge.
